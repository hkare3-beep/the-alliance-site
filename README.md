# The Alliance — Research. Innovate. Impact.

A fully functional website for The Alliance, an interdisciplinary student research and project organization at the University of Illinois Chicago.

## Pages

- **index.html** - Home page with hero section, mission statement, and calls to action
- **about.html** - Organization mission, values, and structure
- **projects.html** - Featured projects and initiatives
- **research.html** - Research pathway information and opportunities
- **events.html** - Upcoming events, workshops, and regular meetings
- **join.html** - How to join The Alliance

## Features

✅ Fully responsive design (mobile, tablet, desktop)  
✅ Clean, modern aesthetic with professional typography  
✅ Smooth scrolling and interactions  
✅ Mobile-friendly navigation  
✅ Organized sections with clear information hierarchy  
✅ Call-to-action buttons throughout  
✅ Professional footer with links  
✅ Fast loading and optimized performance  

## Styling

- **Font:** Space Grotesk (headings), Inter (body)
- **Colors:** Professional blue and amber accents
- **Layout:** Responsive grid system
- **Accessibility:** Semantic HTML, proper contrast ratios

## Getting Started

1. Clone or download this repository
2. Open `index.html` in a web browser
3. All pages are static HTML with embedded CSS and JavaScript
4. No dependencies required

## Customization

### Colors
Edit the CSS variables in `assets/styles.css`:
```css
:root {
  --primary: #2563eb;           /* Primary blue */
  --accent: #f59e0b;            /* Amber accent */
  --text: #1f2937;              /* Dark text */
  --bg: #ffffff;                /* White background */
}
```

### Content
Edit the HTML files directly to update:
- Organization name and tagline
- Event dates and descriptions
- Project details
- Contact information
- Links and navigation
